# **VortyxMind – Security Awareness Training**

**Division:** VortyxSec (Security)  
**Architecture:** LMS / Phishing Simulation (Gophish Architecture)  
**Status:** [PLANNING]

## **1. Executive Summary**

VortyxMind targets the "Human Firewall". It is a Learning Management System (LMS) and Phishing Simulation platform designed to educate employees on security best practices. It tracks risk culture and identifies users who need remedial training.

## **2. Core Features**

### **2.1 Phishing Simulations**

- **Template Library:** Realistic phishing templates based on real-world attacks.
- **Campaign Management:** Schedule and track simulations across an organization.
- **Teachable Moments:** Educational landing pages shown when a user clicks a simulated phishing link.

### **2.2 Security Training**

- **LMS Integration:** Delivery of security training modules (video, quizzes).
- **Progress Tracking:** Monitors employee completion rates and quiz scores.
- **Risk Scoring:** Assigns a security risk score to individual users based on their performance.

## **3. Integration with Vortyx Ecosystem**

- **VortyxPilot:** Automatically enrolls users in training based on incident history (e.g., "User clicked a real malicious link").
- **VortyxGuard:** Can trigger educational popups when a user attempts to run high-risk or prohibited software.
- **VortyxRadar:** Correlates training performance with active security alerts to identify high-risk departments or individuals.
- **VortyxShield:** Provides training compliance data for GRC reports.
